# 知识脑图绘制指南

摘要页里的"知识脑图"是**自动生成**的: 页面加载时由 JavaScript 从各章节标题画出一张左右放射树。**这不是必填项, 也不需要生成时手写 SVG**——只要正文有章节, 脑图就出现; 没有章节, 整块自动移除。

图上文字全部来自章节标题和视频标题, 不扩写、不编造。

---

## 一、它是什么, 不是什么

- **是**: 页面内部由 JS 运行时生成的内联 SVG, 中心是视频主题, 分支是各章节, 与正文一一对应。
- **不是**: 独立交付的脑图图片文件; 不是需要人工设计的复杂图表; 不替代详情章节。
- 跟"一图看懂"(信息图) 的区别: 信息图是**手工设计**的流程/对比/时间线, 讲某一个具体结论; 脑图是**自动映射**全文结构, 讲"这个视频分几块"。两者互不替代, 可同时出现。

---

## 二、数据来源与文字纪律

脑图读三处, 全部来自模板已有内容:

| 图上位置 | 数据来源 | 规则 |
|---|---|---|
| 中心节点 | `<h1>` 视频标题 | 自动截前 8 字, 超长加省略号; `<title>` 里保留完整标题 |
| 分支序号 | 章节 `.ch-num` | 直接用, 与大纲一致 |
| 分支文字 | 章节 `<h3>` 标题 | 默认用原文, 超 20 字自动截断 |

**可选短标签**: 章节标题太长、截断后表意不清时, 在该 `<article class="chapter">` 上加 `data-mind="短标签"`:

```html
<article class="chapter reveal" data-mind="设计的三个误区">
```

- `data-mind` ≤ 20 字, 必须是对该章节标题的**精简改写或原文摘录**, 不能引入新信息。
- 只在截断会失真时才加。多数情况下直接用 `<h3>` 原标题即可, 别为了好看乱改。
- 生成时若加了 `data-mind`, 同步确认 `<title>` 提示里显示的是"序号 + 完整标题", 分支上显示的才是短标签。

**红线**: 每个字都要能在转录稿或章节正文里找到出处。脑图是结构的镜子, 不是新的创作。

---

## 三、生成逻辑 (模板已内置, 无需手改)

模板 `assets/report_template.html` 的脚本段已经实现, 要点:

- 章节数 N → SVG 高度 `max(N × 58 + 52, 150)`, 节点间距固定, 章节再多也不重叠。
- 中心在左 (`x=210`), 分支在右 (`x=470`), 贝塞尔曲线连接。
- 中心节点: `--accent-soft` 底 + `--accent` 描边/文字; 分支节点: `--sheet` 底 + `--rule` 描边 + `--ink` 文字, 序号圆点用 `--accent`。
- 所有颜色走 CSS 变量, 8 套配色 × 深浅主题自动适配, 禁止写死颜色。
- `viewBox="0 0 760 H"` + `width:100%`, 窄屏等比缩放不溢出。
- 有 `role="img"` 和 `aria-label`, 每个分支带 `<title>` 供读屏和悬停。

**不要**在生成摘要时重写这段脚本, 也不要往脑图区块填占位符。它跟大纲导航一样, 是模板的自动能力。

---

## 四、什么时候该注意脑图

| 情况 | 处理 |
|---|---|
| 章节 1-2 个 | 脑图照常生成, 节点少但不空 |
| 章节标题都很短 | 直接用, 不加 `data-mind` |
| 某章标题超 20 字、截断后看不懂 | 给该章加 `data-mind` 短标签 |
| 视频是纯叙事、没有明确分块 | 正文仍按内容分章节, 脑图随之生成; 不要为了脑图硬造章节 |
| 章节为空 (无正文) | 模板自动移除脑图整块, 无需手动删 |

## 五、验收清单

- [ ] 脑图区块存在, 节点数 = 章节数, 序号与大纲一致
- [ ] 图上每个字来自章节标题或 `data-mind`, 无编造、无占位符残留
- [ ] 中心文字来自 `<h1>`, 超长有省略号, `<title>` 是完整标题
- [ ] 超长章节标题已加 `data-mind`, 或截断后仍可理解
- [ ] 颜色全走 CSS 变量, 8 配色 × 深浅主题下文字可读
- [ ] 窄屏下 SVG 等比缩放, 不溢出、不裁字
- [ ] `aria-label` 与每个分支的 `<title>` 齐全
