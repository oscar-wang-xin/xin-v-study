# HTML 视觉规范 (v4)

设计目标: 科技、立体、有动感, 同时保持信息密度与可读性。两套模板共用一套视觉语言:
细网格光晕底纹 + 白色大圆角卡 + 渐变描边与多层阴影 + 强调色点睛, 核心结论是深色面板。
支持 8 套配色 × 浅色/深色两个正交维度。

模板是唯一出处: `assets/report_template.html` 和 `assets/index_template.html`。
本文件只讲原则与判断标准, 具体 CSS 以模板为准, 不要另起炉灶。

---

## 设计上下文

- **读者**: 想花几分钟搞懂一个视频讲了什么的人。
- **场景**: 安静阅读、快速扫读, 桌面为主、手机也能看。
- **气质**: 现代工具感 + 轻微科技感。靠层次、光影和克制的动效建立质感, 不靠堆砌装饰。

---

## 主题架构: 两套正交维度

| 维度 | data 属性 | localStorage 键 | 取值 |
|---|---|---|---|
| 配色 | `data-scheme` | `xvs-scheme` | mecha / business / china / ali / grape / mint / ink / porcelain |
| 明暗 | `data-theme` | `xvs-theme` | light / dark |

- `<head>` 内联脚本在两个维度都在样式生效前初始化: 本地存储优先, 明暗没存过就跟随系统。
- 两页共享同一对键。导航页选了"葡萄籽 + 深色", 打开任何摘要页都是同一套。
- 右上角工具组: 调色盘按钮展开 8 色面板 (显示当前配色中文名), 旁边是日/月明暗按钮。
- 配色切换不重塑结构, 只替换强调色变量。任何配色 × 任何明暗都必须可读。

### 八套配色

| 键 | 名称 | 浅色强调 | 深色强调 | 气质 |
|---|---|---|---|---|
| `mecha` | 机甲冷灰 | `#486273` | `#9db9cc` | 冷钢金属, 低饱和 |
| `business` | 商务蓝 | `#1d4ed8` | `#87a9ff` | 高饱和企业蓝 |
| `china` | 中国红 | `#c8102e` | `#ff6277` | 正红 |
| `ali` | 阿里橙 | `#e85900` | `#ffa257` | 暖橙 |
| `grape` | 葡萄籽 | `#6d28d9` | `#bda3ff` | 深紫, 非荧光 |
| `mint` | 薄荷绿 | `#0a8f6a` | `#5fe0b3` | 青绿, 默认配色 |
| `ink` | 墨水风 | `#30353c` | `#e6e9ee` | 黑白灰极简 |
| `porcelain` | 青花瓷 | `#1c6b8c` | `#74bcd8` | 偏青的钴蓝 |

**禁止使用旧版大红 `#ff4517`。** 中国红是正红 `#c8102e`, 不是橙红。

变量派生机制: `[data-theme]` 定义结构色并把 `--accent` 指向 `var(--a-lt)` 或 `var(--a-dk)`;
`[data-scheme]` 只定义 `--a-lt / --a-dk / --a-soft-lt / --a-soft-dk / --a-rgb`。
var() 运行时解析, 所以两套维度可以自由组合。

### 明确禁止

- 不用霓虹发光、重度毛玻璃 (`backdrop-filter`)、紫蓝大渐变、荧光色。
- 组件颜色一律 `var(--*)` 取色; 只有配色面板的 8 个色块用固定代表色 (它们要显示本色)。
- 不用 emoji 当图标, 小图标用内联 SVG。
- 不写"综上所述""值得注意的是""希望对你有帮助"这类空话。
- 不引用任何外部 CDN / 字体 / 脚本。断网必须能完整打开。

## 立体感从哪来

不是靠大阴影糊一层, 是靠几样东西叠加:

- **底纹**: 固定定位的 46px 细网格 + 两处低透明度径向光晕, 用 mask 渐隐, 不抢正文。
- **卡片**: 主卡 `border-radius: 24px` + 三层阴影 + 顶部 3px 渐变条 + 右上径向光晕。
- **渐变描边**: 区块标题前的小方菱形 (`rotate(45deg)`) 带 4px `accent-soft` 外圈。
- **内高光**: 浅色下功能块加 `inset 0 1px 0 rgba(255,255,255,.45)`, 深色下换极低透明度。
- **巨型序号**: `background-clip: text` 的渐变字, 从强调色过渡到半透明。
- **悬浮抬升**: 卡片和要点 hover 时 `translateY(-3px ~ -6px)` + 强调色阴影。

---

## 动效

- 顶部 3px 滚动进度条, 随滚动填充, 带强调色辉光。
- 摘要页标题栏右侧显示"当前章节序号 / 总数 + 章节名"的浮动指示, 滚动时出现。
- 章节区块用 IntersectionObserver 淡入上移 (`translateY(14px)` → 0), 460ms。
- 结论面板右上装饰圆做 7s 缓慢呼吸缩放。
- 平滑滚动 `scroll-behavior: smooth`, 回顶按钮滚动超过 320px 才出现。
- 缓动统一 `cubic-bezier(.2,.7,.2,1)`, 不用回弹/弹性。
- 尊重 `prefers-reduced-motion`: 关掉后全部静止。

## 摘要页专属结构

### 大纲导航

放在头部元信息下方, `<nav class="toc">`。**生成时不需要填任何占位符**:
脚本在运行时从每个 `.chapter` 的 `.ch-num` 与 `.ch-body h3` 自动生成条目,
同时给章节补 `id="sec-N"`。章节标题超长用 `text-overflow: ellipsis` + `title` 属性保留全文。

- 条目是 `auto-fill, minmax(215px, 1fr)` 的响应式网格。
- 当前章节自动加 `.active`: 强调色淡底 + 左侧 3px 强调条。
- 点击条目跳到对应章节, 章节设 `scroll-margin-top: 26px` 避免贴顶。

### 回到顶部

右下角固定按钮, 滚动 > 320px 淡入, 点击平滑回顶。圆角 14px + 主阴影 + 强调色箭头图标。
导航页也有同一个按钮, 行为一致。

## 字体

全部系统字体, 不联网加载。标题和正文用无衬线粗体, 元信息用等宽。

```css
--font-body: "Segoe UI", "PingFang SC", "Microsoft YaHei", "Hiragino Sans GB", system-ui, sans-serif;
--font-mono: ui-monospace, "SF Mono", Consolas, monospace;
```

- 主标题: `clamp(2rem, 5.6vw, 3.4rem)`, 700, 字距 `-0.02em`, 行高 1.16。
- 段落: `1.0625rem` (约 17px), 行高 1.75。
- 正文段宽控制在 30-38 个汉字, 不拉满卡片。
- 等宽字体只用于 kicker、元信息标签、序号、图注、药丸, 不写正文。

## 布局与层级

- 摘要页 `max-width: 980px`; 导航页 `max-width: 1080px`。
- 内容包在白色大圆角卡里, 与灰画布留出间距。
- 卡片内功能块 `border-radius: 14-18px`, 浅色带边框和内高光。
- 元信息区三列等宽浅灰块 (来源 / 时长 / 整理)。
- 内容详解三列网格: 章节编号 / 文字 / 图片, 每章一个浅灰圆角块;
  偶数段加 `flip` 类让图文左右互换, 制造阅读节奏。
- 标题、kicker、图注贴左, 靠留白和对齐建立秩序。

## 组件要点

### 头部

渐变实底白字 kicker 药丸 + 日期戳等宽小字居右 + 大标题 + 三列元信息块 + 大纲导航。

### 核心结论

整页唯一的深色面板: 近黑渐变底 (纯色回退) + 左侧 4px 强调色条 + 右上呼吸圆 +
强调色小方块标签 + 白色粗体大字。

### 区块标题

旋转 45° 的强调色小菱形 + 中文粗体 + 英文等宽小字, 右侧细线延伸补齐。
固定三块: 核心要点 KEY POINTS / 一图看懂 AT A GLANCE / 内容详解 IN DETAIL。

### 一图看懂

可选区块。内联 SVG 画在浅灰圆角容器里, 规则见 `infographic_guide.md`。
视频没有清晰结构时 **整段删掉**, 不留空壳。SVG 全部用 `var(--*)` 取色。

### 导航页

工具栏: 搜索框聚焦时加 3px 强调色柔光圈; 排序/顺序是药丸控件; 计数居右。
列表卡: 渐变底 + 左侧强调条 (hover 时展开) + 渐变巨型序号 + 标题 hover 变强调色 +
简介三行截断 + 底部药丸 (来源 / 日期 / 时长)。hover 上移 6px 并出强调色阴影。

### 尾部

一条细边框之上, 一句客观说明用次要色小字。**不加任何署名或落款。**
