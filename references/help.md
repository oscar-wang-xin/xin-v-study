# xin-v-study 使用帮助

给一个视频，产出一份图文并茂的单页 HTML 摘要。内容只来自视频本身的讲解，去口语、不扩写、不失真；配图是视频里的真实画面，不是生成的示意图。成品是单个自包含 HTML 文件，断网也能完整打开。

## 怎么用

直接把视频给我，说一句"总结这个视频"就行。三种来源都支持：

- 本地视频文件（如一个 `.mp4` 路径）
- 媒体直链（`.mp4` / `.m4a` 等）
- 视频平台网页地址（B站、YouTube 等）

## 保存到哪里

- **你指定了目录** → 直接存到那个目录，不存在就自动创建。
- **你没指定目录** → 我会先问你，让你从这几项里选：
  1. 配置里的默认目录（推荐，路径见下方）
  2. 当前工作目录
  3. 其他路径（你直接告诉我完整路径）

不会在你没表态的情况下私自决定存放位置。配置里的默认目录只是其中一个推荐选项，不是自动答案。

改默认目录：复制 `config.example.json` 为 `config.json`，改 `default_output_dir` 的值。绝对路径、相对路径都行，相对路径按项目根目录解析。

## 你会得到什么

- 一份 `<视频标题>.html`：文件名取自视频内容，顶部有大纲导航、回顶按钮、滚动进度条；右上角可切换 8 套配色和浅色/深色。
- 一个 `_list.html`：所在目录的卡片导航页，按时间或名称排序，可搜索，点卡片在新窗口打开摘要。每生成一份摘要都会自动更新它。

摘要结构：核心结论 → 3-6 条要点 → 图文交错的内容详解 → 可选的信息图 → 尾部客观说明。信息图只在视频有清晰流程/并列/对比/时间线时画，文字全部来自转录稿。

## 边界

- 转录依赖 WorkBuddy 内置的音频转录能力；脱离 WorkBuddy 单独跑脚本完不成转录这一步。
- 超过约 5 小时或 1 GB 的视频需要切片转录。
- 需要登录态的平台视频（会员清晰度、年龄限制等）可能需要你提供 cookies。
- 没有讲解语音的视频会退化为画面理解，并在摘要中如实注明。
- 内容纪律：视频没说的一律不写；拿不准的地方用保守说法。
